Download & try Rizi

Currently for Apple Silicon Macs, with its runtime included: no separate Node.js installation is needed. The preview is not notarized. You configure your own model and pay the fees for your chosen service.

Other platforms, including Web / PWA and Android, are still in planning. They are not available yet, and there is no confirmed release date.

How do I install it after an invitation?
  1. Get the package through the invitation and verify its checksum using the included instructions.
  2. Read the installation guide and drag the app into Applications. Open it yourself for the first time and follow the macOS system prompts.
  3. Configure your model to start the trial. There are no automatic updates; follow the included backup instructions before upgrading.

A few things to know

Can I download Rizi now?+

You can request a trial; there is no public download yet. The current candidate is 0.9.0-rc.4 for macOS on Apple Silicon, with no automatic updates. A request does not immediately provide a package or invitation. Leave a valid email through the download and trial section.

Does Rizi automatically remember everything?+

Important memories are yours to confirm, correct, or forget. Rizi does not promise to remember every conversation accurately. A sense of familiarity should never replace your judgment about the content.

Does it work completely offline?+

That is not a promise we can make. Memories and work materials are managed locally. Using a model or an external service involves the service and configuration you choose. Local storage does not make the whole collaboration offline.

What is a Mod?+

Think of a Mod as a work card: a way to set out the requirements before working on a task together. This walkthrough shows a single research Mod. Combining multiple Mods is still a separate exploration.
